# 🌄 Parallax App

> A visual front-end experiment using layered imagery, scrolling, and CSS parallax effects.

## Overview

Parallax App explores how depth and movement can be created in a browser through layered backgrounds, responsive layout, and scroll-driven presentation.

## Run Locally

Open [`index.html`](./index.html) directly, or use a local server:

```bash
python -m http.server 5500
```

Visit <http://localhost:5500>.
